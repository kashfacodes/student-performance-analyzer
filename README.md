# Student Performance Analyzer

A Python data analysis project that analyzes student marks using Pandas and visualizes performance using Matplotlib.

## Features

- Calculate subject averages
- Find the overall top student
- Find the topper in each subject
- Calculate individual student averages
- Visualize student performance with a bar chart

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV data

## How to Run

Install the required libraries:

pip install pandas matplotlib

Then run:

python student_analyzer.py
